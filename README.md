# MusicShell

MusicShell 是一个个人学习用途的本地音乐文件管理与播放工具。它本身不包含任何音乐内容，只面向用户设备中已经存在、且用户拥有合法获取权利的本地音频文件。

## 当前状态

- 已建立 Java + XML 的 Android 基础外壳。
- 首次启动会显示《学习研究协议与版权警告》。
- 首页保留本地音乐扫描入口、关于与免责声明入口。
- 已配置 Material Design 3 基础主题色，并支持深浅色模式。
- 已实现本地音乐扫描功能（基于 MediaStore）。
- 已实现本地播放最小闭环：点击歌曲播放/暂停、底部迷你播放栏、播放状态高亮。
- 已实现播放进度条（SeekBar）和上一首/下一首功能。
- 支持播放列表管理，歌曲自动切换，进度实时更新。
- 使用系统 MediaPlayer 异步播放，Activity 销毁时自动释放资源。

## 合规边界

- 不内置任何商业音乐平台接口、域名、API Key 或 Token。
- 不提供音乐推荐、排行榜、歌单分发或云端内容服务。
- 不实现绕过 DRM 或加密保护的技术措施。
- 不上传用户音乐文件、播放记录或个人数据。
- 下载、脚本扩展和网络访问能力会在后续阶段单独设计，并保留版权提示和安全拦截。

## 技术约束

- 语言：Java
- 布局：XML
- 最低支持：Android 7.0，API 24
- 目标 SDK：36
- 方向：手机竖屏优先，后续补平板适配

## 构建

在项目根目录运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

构建产物位于 `app/build/`，该目录不会提交到 Git。
